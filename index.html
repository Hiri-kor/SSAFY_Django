Django 필수 명령어 & 문법 치트시트

1. 프로젝트 초기 설정 & 실행

# 가상환경 생성 및 활성화

$ python -m venv venv

$ source venv/Scripts/activate

# 패키지 설치 및 고정

$ pip install django

$ pip freeze > requirements.txt

# 프로젝트 & 앱 생성

$ django-admin startproject firstpjt .

$ python manage.py startapp articles

$ python manage.py runserver

2. Model & Migrations & Admin

# 설계도(migration) 생성 및 DB 반영

$ python manage.py makemigrations

$ python manage.py migrate

# 마이그레이션 상태 및 SQL 확인

$ python manage.py showmigrations

$ python manage.py sqlmigrate articles 0001

# 관리자(Superuser) 계정 생성

$ python manage.py createsuperuser

3. Django ORM 핵심 QuerySet API

# 생성 (Create)

article = Article(title='제목', content='내용')

article.save()

# 조회 (Read)

Article.objects.all()

Article.objects.filter(title='제목')

Article.objects.get(pk=1)

# 수정 & 삭제 (Update & Delete)

article.title = '수정제목'; article.save()

article.delete()

4. Form / ModelForm & Static/Media

form = ArticleForm(request.POST, request.FILES)

if form.is_valid():

    article = form.save()
